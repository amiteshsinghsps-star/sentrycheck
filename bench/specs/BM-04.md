# BM-04: Static-versus-Dynamic Ablation

## Objective
Measure the empirical accuracy difference between the static candidate extraction arm and the live dynamic diff arm on identical workloads using ABBA positional interleaving on a single release and host.

## Interleaving Scheme
- Case arm sequence: `[static, live, live, static]` (36 recorded runs across 9 cases).
- Positional drift protection: detects whether warm host caches or transient system load systematically bias early vs late execution arms.

## Findings & Methodology
- Static-only analysis produces no compatibility verdict by design (returns exit code 2, classified as `indeterminate`), because static extraction cannot verify runtime tolerance or graceful library fallbacks.
- Live dynamic diff arm achieves 8/9 accuracy on the pilot corpus, matching BM-01.
- Evaluated on a single gVisor release (20260921.0) and a single host (WSL2 desktop).
