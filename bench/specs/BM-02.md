# BM-02: Static Extraction Accuracy

## Objective
Quantify the precision and recall of static syscall candidate extraction against a corpus of ELF binaries with known ground truth.

## Ground Truth Procedure
1. Baseline test binaries compiled with known syscall invocations (direct syscall instruction, libc wrappers).
2. OCI image layouts representing real runtimes (Go runtime, Postgres 18, Musl libc).
3. Ground-truth expected syscall sets established per target.
4. Static candidate extraction executed via `sentrycheck scan <target> --static-only --format json`.

## Metrics
- Extracted count vs expected count per target.
- Per-binary recall = `hits / expected_count`.
- Per-binary precision = `hits / extracted_count`.
- Execution wall time (ms).

## Execution
```bash
python -m bench suite BM-02
# Output written to bench/analysis/tables/bm02_static_extraction.csv
```
