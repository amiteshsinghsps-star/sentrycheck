# BM-08: Tool Performance and Scalability Ladders

## Objective
Benchmark scan execution time and cache acceleration across images of varying complexity and size (from 0MB synthetic fixtures up to 60MB multi-layer container images).

## Workloads Tested
- `synthetic-baseline`: 0MB minimal static binary.
- `postgres-18-io-uring`: 47.4MB database container with rich ELF symbol tables.
- `registry-node`: 58.5MB Node.js image with nested `node_modules` dependencies.
- `registry-python`: 41.3MB Python image with multiple shared library binaries.

## Metrics
- Cold scan duration (ms) with `--no-cache`.
- Warm scan duration (ms) with persistent `.sentrycheck/cache`.
- Cache speedup factor (`cold_ms / warm_ms`).

## Execution
```bash
python -m bench suite BM-08
# Output written to bench/analysis/tables/bm08_scalability.csv
```
