# BM-13: Reproducibility and Provenance

## Objective
Verify that analysis results, tables, and figures can be rebuilt bit-identically across independent executions and across disparate Python execution environments (e.g., Windows CPython vs Linux/WSL2 CPython).

## Procedure
1. Execute `bench analyze --out .tmp/bm13-a` under local interpreter.
2. Execute `bench analyze --out .tmp/bm13-b` under local interpreter.
3. Compare SHA256 hashes of all generated CSV tables and SVG figures.
4. Execute rebuild under WSL2 Python interpreter and cross-verify hashes against Windows artifacts.

## Acceptance Criteria
- 100% bit-identical match across rebuilds (zero hash divergence).
- Deterministic quantization: floating point values rounded to 6 decimal places, ISO timestamps standardized, JSON keys canonically sorted.
