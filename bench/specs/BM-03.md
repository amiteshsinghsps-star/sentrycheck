# BM-03: Dynamic Fidelity & Tracer Perturbation

## Objective
Measure whether trace ingestion, perturbation, or malformed trace events induce parser crashes, silent event drops, or verdict flips.

## Fault Families Evaluated
- `truncated-mid-line`: Strace log abruptly truncated across a syscall argument boundary.
- `corrupted-errno`: Negative, non-numeric, or oversized errno strings.
- `injected-quote-marker`: Malformed quoting inside string argument delimiters.
- `dropped-return`: Syscall entry record with missing `unfinished` / resume counterpart.
- `timestamp-skew`: Non-monotonic guest timestamp sequences.
- `absurd-tid`: PIDs exceeding OS limits (`PID > 4,194,304` or >7 digits).

## Acceptance Criteria
- Zero scanner panics or unhandled exceptions on hostile trace input.
- Malformed records must be discarded with explicit unparsed line counts or flagged as incomplete rather than silently accepted.

## Execution
```bash
python -m bench suite BM-03
# Output written to bench/analysis/tables/bm03_dynamic_fidelity.csv
```
