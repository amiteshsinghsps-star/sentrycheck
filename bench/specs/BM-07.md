# BM-07: Robustness and Adversarial Input Handling

## Objective
Evaluate the parser and scanner robustness against malformed OCI image layouts, corrupt ELF headers, and path traversal attempts.

## Mutation Categories
- `malformed-elf-header`: Truncated ELF header, corrupted architecture/e_machine field.
- `elf-section-table-loop`: Circular or overflowing section header table offsets.
- `tar-layer-huge-declared-size`: Sparse / base-256 GNU tar header declaring oversized file payloads.
- `path-traversal-layer`: Tar archives containing relative path escapes (`../../etc/passwd`).
- `empty-image-manifest`: Truncated or empty JSON descriptor blobs.
- `zero-byte-binary`: Empty ELF executable files.

## Acceptance Criteria
- Scanner must fail closed: return non-zero exit code or explicit validation error.
- Memory consumption must remain strictly bounded (<128MB RSS).
- Zero uncaught panics or host resource exhaustion.

## Execution
```bash
python -m bench suite BM-07
# Output written to bench/analysis/tables/bm07_adversarial.csv
```
